# Eurico, o Presbítero — apresentação (Literatura Portuguesa I, UECE/FECIL)

Site estático: HTML + Tailwind (CDN) + CSS + JS. Sem build.

## Rodar local
    python3 -m http.server 8000   # abrir http://localhost:8000

## GitHub Pages
Suba a pasta num repositório → Settings → Pages → Deploy from branch → `main` / root.

## Atalhos
← → / espaço: navegar · N: notas de fala · O: visão geral · F: tela cheia · Ctrl+P: PDF

## Antes de apresentar (pendências)
- Slides 7 e 17: ano/edição da Martin Claret (página de créditos).
- Slide 14: inserir trecho da edição Martin Claret com página.
- Slides 10–12: conferir no livro parentescos, Cavaleiro Negro e desfecho.
- Slide 17: conferir edições dos manuais; acrescentar fontes indicadas pela docente.
- Brasão: o arquivo vem da Wikimedia Commons; troque `assets/brasao.png` pelo oficial (uece.br).
